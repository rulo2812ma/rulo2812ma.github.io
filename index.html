¿Qué aprenderás en este curso?

Aprende los fundamentos de CSS y descubre cómo utilizar selectores, colores, tipografías, el modelo de caja, Flexbox, CSS Grid, posicionamiento, animaciones y propiedades personalizadas para mejorar la apariencia de tus páginas web.

CSS Layouts

Los diseños CSS permiten organizar los elementos de una página. Flexbox ayuda a alinearlos en filas o columnas, mientras que Grid permite crear distribuciones mediante filas y columnas.

Transiciones y animaciones

Las animaciones y transiciones CSS permiten modificar propiedades visuales gradualmente o crear movimientos mediante @keyframes. Son útiles para destacar botones, mostrar elementos y mejorar la interacción con el usuario.

Sass

Sass es un preprocesador que amplía CSS con variables, anidación y otras herramientas. Ayuda a organizar hojas de estilo grandes y permite generar CSS que los navegadores pueden interpretar.

Preguntas frecuentes

Aquí encontrarás respuestas sobre los fundamentos de CSS y las herramientas que se utilizan para construir páginas web claras, atractivas y adaptables a diferentes pantallas.

¿Qué es CSS?

CSS significa hojas de estilo en cascada. Es un lenguaje que define la presentación visual de documentos HTML: colores, fuentes, tamaños, márgenes, bordes y distribución. Separar el contenido de su apariencia facilita mantener y actualizar un sitio web.

¿Qué aprenderé en este curso?

Aprenderás a utilizar selectores, colores, tipografías, márgenes, rellenos, bordes y el modelo de caja. También conocerás Flexbox para alinear elementos, CSS Grid para crear filas y columnas, media queries para adaptar el diseño y transiciones para añadir cambios visuales suaves.

¿Qué es CSS Grid?

CSS Grid es un sistema de diseño bidimensional que permite distribuir elementos en filas y columnas. Se activa con display: grid y puede configurarse con propiedades como grid-template-columns, gap y grid-template-rows. Es útil para galerías, tarjetas y estructuras completas de una página.

¿Estás listo para aprender CSS?

Empieza practicando los selectores y el modelo de caja. Después crea distribuciones con Flexbox y Grid, y utiliza media queries para adaptar tu página a distintos tamaños de pantalla. Finalmente, prueba pseudoclases y transiciones para mejorar la interacción.
